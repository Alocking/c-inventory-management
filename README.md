# 进销存 / 库存管理系统

基于 C 语言（标准库）实现的终端进销存管理系统，支持商品管理、入出库操作、AVL 索引、FIFO 单据队列、撤销操作以及本地文件持久化。

## 功能特性

| 模块 | 功能 | 说明 |
|------|------|------|
| 商品管理 | 增 / 删 / 改 / 查 | 支持按 SKU 查询，删除前校验库存为 0 |
| AVL 索引 | 万级 SKU 快速查找 | 按 SKU 字符串建立 AVL 平衡二叉树，O(log n) 查询 |
| 入库 / 出库 | 采购入库、销售出库 | 自动更新库存，库存不足时拒绝出库 |
| FIFO 队列 | 单据按序处理 | 入出库单据进入循环队列，先进先出 |
| 撤销操作 | 撤销最近一次操作 | 栈实现 LIFO 撤销，自动反向更新库存 |
| 文件持久化 | 二进制文件存储 | `product.dat` 存商品，`stock_order.dat` 存单据，含魔数校验 |

## 数据结构

| 结构 | 用途 |
|------|------|
| 有头双向循环链表 | 商品存储，支持遍历 |
| AVL 平衡二叉树 | 按 SKU 建立索引，O(log n) 查找 |
| 环形数组队列 | FIFO 单据队列 |
| 数组栈 | 撤销操作栈 |

## 编译与运行

### Ubuntu / Linux

```bash
# 编译
make

# 运行
./inventory

# 运行测试
make test-run

# 清理
make clean
```

### Windows (MinGW)

```bash
# 编译
mingw32-make

# 运行
./inventory.exe

# 测试
mingw32-make test
./test.exe
```

### 编译选项

| 选项 | 说明 |
|------|------|
| `-std=c99` | 使用 C99 标准 |
| `-Wall -Wextra` | 开启全部警告 |
| `-O2` | 二级优化 |

## 验收标准

| 编号 | 验收项 |
|------|--------|
| AC-1 | 商品增删改查功能正常，删除时库存非 0 拒绝 |
| AC-2 | 入库/出库正确更新库存，库存不足拒绝出库 |
| AC-3 | 撤销操作后库存恢复正确 |
| AC-4 | 单据按 FIFO 顺序处理 |
| AC-5 | 重启程序后商品和单据数据完整恢复 |
| AC-6 | 1 万 SKU 查询耗时 < 10ms |
| AC-7 | 编译零警告（`-Wall -Wextra`） |
